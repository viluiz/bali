# Roteiro viagem

Site estático pronto para publicar no GitHub Pages.

## Arquivos

- `index.html`: página principal do roteiro.

## Como publicar no GitHub Pages pela interface web

1. Crie um repositório no GitHub, por exemplo `roteiro-edimburgo`.
2. Faça upload dos arquivos `index.html` na raiz do repositório.
3. Confirme o upload com **Commit changes**.
4. Acesse **Settings** do repositório.
5. No menu lateral, selecione **Pages**.
6. Em **Build and deployment**, selecione **Deploy from a branch**.
7. Em **Branch**, selecione `main` e a pasta `/ (root)`.
8. Salve. O site será publicado pelo GitHub Pages no endereço do repositório.

## Observações

- Os mapas são carregados via OpenStreetMap.
- As imagens são carregadas de páginas públicas de Wikimedia Commons/Pixabay.
- O site precisa de internet para carregar mapas e fotografias externas.
